# Privacy Policy — Meta Leads PoC Demo

**Last updated: 2 November 2026**

## 1. About this demonstration

Meta Leads PoC Demo is a demonstration project built to test the integration between Meta Lead Ads, a backend service, Supabase and a React Native application.

This project is not a commercial lead-generation service.

## 2. Information we collect

When you submit the demonstration Instant Form, we may receive:

- Full name
- Email address
- Phone number
- Meta lead, Page and form identifiers
- Submission date and time

## 3. How we use your information

We use submitted information solely to:

- Demonstrate and test Meta Lead Ads webhook integration.
- Display submitted leads in a React Native demonstration application.
- Test backend processing and database functionality.

We do not use this demonstration to send marketing messages or sell personal information.

## 4. How information is stored

Submitted lead information is processed by our backend and stored in a Supabase database for demonstration and testing purposes.

Meta and Supabase may process information as part of providing their respective services. Access to stored lead information is restricted to the people operating this demonstration.

## 5. Data retention and deletion

We retain test submission information only for as long as it is needed for the demonstration. Test records will be deleted when they are no longer required.

You may request deletion of your submitted test information using the contact details below.

## 6. Data sharing

We do not sell or rent personal information. Information is processed through Meta's lead-generation services and Supabase as necessary to operate this demonstration. We do not intentionally share it with other parties for advertising or marketing.

## 7. Security

We take reasonable technical measures to protect stored information. However, no internet-based system can guarantee absolute security.

## 8. Your choices and requests

If you want to ask about, access or request deletion of information submitted through this demonstration, contact us using the email address below.
